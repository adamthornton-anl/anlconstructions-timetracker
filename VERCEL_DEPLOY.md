# Deploy to Vercel in 3 Minutes

Your app is ready for Vercel. Here's exactly what to do:

## Step 1: Install Vercel CLI

```bash
npm install -g vercel
```

## Step 2: Deploy

```bash
cd /home/agent/workspace
vercel
```

## Step 3: Answer the prompts

When Vercel asks:
- **Are you in the correct project?** → Yes
- **Which scope?** → Your personal account
- **Project name?** → `anlconstructions-timetracker` (or whatever you want)
- **Production?** → Yes

## Done! 🎉

Vercel will output a URL like:
```
https://anlconstructions-timetracker.vercel.app
```

**Paste that URL into your iPhone's Safari browser and you're live!**

---

## What happens next?

- Your backend API goes live
- Your frontend loads on that domain
- All data saves to your Supabase database
- Workers can access it from anywhere
