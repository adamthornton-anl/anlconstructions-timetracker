# Anlconstructions Time Tracker - Quick Reference Card

## 🚀 START HERE

### Open the App
```
1. Find: time_tracker_app.html
2. Double-click to open in browser
3. Done! Start using.
```

---

## 📋 TABS & FEATURES

| Tab | Purpose | Quick Start |
|-----|---------|------------|
| ⏰ **Time Entry** | Log daily work | Select worker → Click "Now" buttons → Save |
| 👷 **Workers** | Manage staff | Enter name → Add hourly rate → Add Worker |
| 📦 **Materials** | Track supplies | Describe what needed → Set priority → Submit |
| 📋 **Tasks** | Daily todo list | Create task → Assign worker → Mark done |
| 📊 **Reports** | View analytics | Click tab to see summary stats |

---

## ⏰ TIME ENTRY - STEP BY STEP

```
1. Click ⏰ Time Entry tab
2. Select worker from dropdown
3. Click "Check In Now"
4. Click "Lunch Start Now"
5. Click "Lunch End Now"
6. Click "Check Out Now"
7. (Optional) Add notes
8. Click "💾 Save Time Entry"
```

**Result:** App automatically calculates hours worked!

---

## 👷 ADD A WORKER - STEP BY STEP

```
1. Click 👷 Workers tab
2. Enter worker name *required
3. Enter email (optional)
4. Enter phone (optional)
5. Enter position (optional)
6. Enter hourly rate (optional)
7. Click "➕ Add Worker"
```

**Result:** Worker appears in dropdown for time entry!

---

## 📦 REQUEST MATERIALS - STEP BY STEP

```
1. Click 📦 Materials tab
2. Select worker (optional)
3. Describe what you need *required
4. Enter quantity (optional)
5. Enter unit: bags, boxes, litres (optional)
6. Set priority: Low/Normal/High/Urgent
7. Click "📦 Submit Request"
```

**Result:** Request tracked in Materials table!

---

## 📋 CREATE A TASK - STEP BY STEP

```
1. Click 📋 Tasks tab
2. Enter task title *required
3. Add description (optional)
4. Assign to worker (optional)
5. Set priority: Low/Normal/High/Urgent
6. Click "➕ Add Task"
```

**Result:** Task appears in daily list!

---

## 📊 VIEW REPORTS - STEP BY STEP

```
1. Click 📊 Reports tab
2. See stats:
   • Total workers
   • Time entries logged
   • Pending materials
   • Active tasks
3. Scroll down for worker summary
4. See hours per worker & last entry
```

**Result:** Instant analytics view!

## ⚙️ COMMON TASKS

### How to delete a worker?
```
👷 Workers tab → Find worker → Click "Delete" button
```

### How to view time entries for a date?
```
⏰ Time Entry tab → They display automatically when saved
```

### How to mark a task complete?
```
📋 Tasks tab → Find task → Click "Delete" to remove
(Status update coming in next version)
```

### How to export data?
```
📊 Reports tab → Right-click table → "Print" or "Save as PDF"
Or use browser: Ctrl+P (Windows) or Cmd+P (Mac)
```

### How to clear all data?
```
⚠️ Browser Settings → Clear Cache & Cookies
(Warning: This deletes all saved data!)
```

## 🔧 TROUBLESHOOTING

| Problem | Solution |
|---------|----------|
| App won't open | Try different browser (Chrome recommended) |
| Data disappeared | Don't clear browser cache (it deletes saved data) |
| Hours not calculating | Make sure all time fields are filled |
| Buttons not working | Refresh page (F5) |
| Can't add worker | Make sure name is filled in |
