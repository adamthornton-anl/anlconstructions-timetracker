## Quick Deploy (Pick One)

### 🎯 RENDER.COM (Easiest - Recommended)

1. Go to: **https://render.com**
2. Sign up with GitHub (use your GitHub account)
3. Click **"New +"** → **"Web Service"**
4. Select repo: **adamthornton-anl/anlconstructions-timetracker**
5. Leave all defaults
6. Click **"Create Web Service"**
7. Wait 3 minutes
8. You get a live URL like: `https://anlconstructions-timetracker.onrender.com`

**Done!** Open that URL on your iPhone.

---

### Alternative: VERCEL

1. Go to: **https://vercel.com/dashboard**
2. Find project: **anlconstructons-timetracker-2-0**
3. Click **"Redeploy"**
4. Wait 60 seconds
5. Live at: **https://anlconstructons-timetracker-2-0.vercel.app**
